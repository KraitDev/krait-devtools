## Features

* Syntax highlighting
* Auto formatting support
* Validation tooling
* File icons for `.kr`
* Comment support
* Bracket matching
* VS Code snippets
* Theme-compatible scopes

## File Support

Supported files:

* `.kr`

The extension includes:

* custom file icons
* syntax-aware highlighting
* formatter integration
